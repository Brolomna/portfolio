# Anmol Siwa — Link Hub

Futuristic personal link hub for Anmol Siwa.

Replace the profile photo by swapping `public/profile.svg` with your image and updating `profileImage` in `src/data/site.ts`.

All destinations live in `src/data/site.ts` (`urls`). They start as placeholders (`#`).

```bash
npm install
npm run dev
```
